# HER AREA — Women's Local Discovery Platform (Mobile App)

This repository contains the enterprise production-grade Flutter application for **HER AREA**, a local business discovery platform tailored for women to discover nearby trusted stores, boutiques, maggam work specialists, bridal studios, and more.

## Architecture
- **Layer:** Clean Architecture (Domain, Data, and Presentation layers)
- **State Management:** Riverpod 2.0
- **Design System:** Material 3 with tailored color tokens and dynamic responsive widgets
- **Phase 1 Mode:** Interactive UI and application architecture powered by a Mock Data Repository Engine
